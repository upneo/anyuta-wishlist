# Виш-лист Анюты

Сайт на GitHub Pages: https://upneo.github.io/anyuta-wishlist/

Страница и фотографии лежат в корне репозитория. Ссылки на Wildberries и Ozon открываются из карточек.

## Бронирование

Кнопки используют Supabase Edge Function `anyuta-reservations` в подключённом проекте `Agat-eco`. Отдельная таблица `public.anyuta_reservations` создаётся миграцией в `supabase/migrations/`. Исходник функции хранится в `supabase/anyuta-reservations/`.

Бронь общая для всех посетителей. При выборе подарка браузер сохраняет секретный токен только на устройстве выбравшего; с этого устройства бронь можно отменить. Публичный ключ Supabase находится в странице, служебный ключ используется только внутри функции. Анонимным посетителям разрешено быстро читать только названия занятых подарков; хеши токенов и запись через таблицу закрыты.
