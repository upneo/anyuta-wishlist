# Виш-лист Анюты

Сайт: `index.html` и фотографии в `assets/`. Ссылки на Wildberries и Ozon открываются из карточек.

## Публикация

В репозитории открой **Settings → Pages**, выбери **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажми **Save**. После публикации сайт будет на `https://upneo.github.io/anyuta-wishlist/`.

## Бронирование

Кнопки обращаются к API исходного сайта `https://anyuta-wishlist-2026.awarewolf1.chatgpt.site/api/reservations`. GitHub Pages размещает только статические файлы. Пока API не разрешает обращения с GitHub Pages, кнопки будут показывать «Бронь временно недоступна». Если этот адрес недоступен посетителям без VPN, для общих броней нужен другой сервер.
